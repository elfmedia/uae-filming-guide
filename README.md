## 🚁 Drone & Aerial Cinematography Rules (2026 Mandate)

1. **Maximum Operating Ceiling:** 400 ft (120 meters) Above Ground Level (AGL).
2. **Visual Line of Sight (VLOS):** RPAS operations must remain within direct visual line of sight of the certified remote pilot unless a BVLOS flight corridor approval has been granted.
3. **No-Fly Geofencing:** Immediate 5 km prohibition around all civilian and military airports, sovereign royal compounds, oil & gas industrial installations, and diplomatic zones.
4. **Third-Party Aviation Liability Insurance:** Minimum USD $1,000,000 to $5,000,000 aviation policy required naming civil aviation authorities.

## 💰 Abu Dhabi 30%+ Cash Rebate Breakdown

The **Abu Dhabi Film Commission (ADFC)** rebate delivers a 30% cash return (scaling up to 35%) on qualifying spend in Abu Dhabi:
- **Commercial Advertisements:** Minimum qualifying expenditure of USD $25,000 (AED 91,800).
- **Television Series / Documentaries:** Minimum qualifying expenditure of USD $50,000 (AED 183,600).
- **Feature Films:** Minimum qualifying expenditure of USD $70,000 (AED 257,000).
- **Local In-Country Value:** Working with MoIAT ICV-certified partners like elf media (ICV #154596) streamlines the post-production expenditure audit.

## 📦 Equipment Customs & ATA Carnet

Cinematography packages entering via Abu Dhabi International (AUH) or Dubai International (DXB) are exempt from 5% customs duties and VAT deposits when declared under an **ATA Carnet**:
- Equipment must be itemized with precise model and serial numbers.
- Consumables (gaffer tape, fog fluids, disposable batteries) must be declared separately.
- Wireless transmitters (Teradek, DJI Transmission) operating on specialized frequencies require TDRA radio spectrum approval.

This repository is built as a zero-dependency, high-performance static website ready for GitHub Pages:

Run the included helper script:
```bash
./publish.sh
```
Follow the interactive prompts to enter your GitHub username/organization (e.g. `elfmedia`) and Personal Access Token (PAT).

### Method B: Manual Git Commands
```bash
# 1. Add your remote
git remote add origin https://github.com/elfmedia/uae-filming-guide.git

# 2. Push to main
git branch -M main
git push -u origin main
```

### Method C: Enable GitHub Pages in Repository Settings
1. Navigate to `https://github.com/elfmedia/uae-filming-guide/settings/pages`.
2. Under **Build and deployment > Source**, select **GitHub Actions** (or `Deploy from a branch` -> `main` / `root`).
3. Your site will immediately be live at `https://elfmedia.github.io/uae-filming-guide/` with a DA 96+ root backlink to `https://elfmedia.ae`.
